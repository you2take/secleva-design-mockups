## 3. セクション別 具体実装メモ

### Hero（書き換え）

**現状コード**：
```html
<h1>サロンオーナーの 1 日に、<br><span class="text-line-green">AI 秘書がいたら。</span></h1>
<p>マッサージ・整体の店主のための、LINE で完結する予約・接客アシスタント。</p>
```

**v2 案**：
```html
<h1>変わるのは、<br><span class="text-line-green">あなたの時間だけ。</span></h1>
<p>お客様の予約は、いつものまま。<br>あなたは、何もしなくていい。</p>
```

### ダブルストーリー（新設）

**レイアウト**：
- モバイル：上下 2 段（顧客視点 → オーナー視点）
- PC：左右 2 カラム

**コア比較表**：
| お客様の体験（変わらない） | あなたの体験（変わる） |
|---|---|
| LINE 内のカレンダーで時間選択 | 予約電話 1 日 30 分 → 0 分 |
| 「明日 14 時で」のチャット OK | 夜の予約調整 → AI 任せ |
| 4 言語自動対応 | カルテ記入 → 施術後 1 分 |
| 24 時間 365 日いつでも | HPB の月 5 万円 → ¥2,480 |

**ビジュアル**：
- 左：LINE 内 HPB 風カレンダー UI スクショ（モック制作要）
- 右：オーナーの 1 日 Before/After タイムライン

### 漫画ストーリー（新設）

**配置**：トリースバーの下、ペインの前

**実装**：
- 5 コマを横スワイプ（モバイル）/ 横並び（PC）
- 1 コマあたり画像 + キャプション 1 行
- META 広告クリエとして転用

**初期投資**：AI 生成 5 本 ¥30,000 程度

### Compare（書き換え）

**v1**：機能比較表（10 機能 × 5 社）
**v2**：**「顧客体験 × コスト構造」の 2 軸マトリクス**

```
         顧客 UX 変わる        顧客 UX 変わらない
高コスト │ —                    │ HPB / Beauty Merit
低コスト │ MUSUBU / Bot 系       │ ★ Secleva
```

メッセージ：**「顧客には HPB と同じ体験、あなたには HPB の 1/20 のコスト」**
