## 1. 6 者議論の結論

### A. ホットペッパー風 UI 戦略 → **採用（戦略の中核に格上げ）**

**論点**：顧客（来店客）の予約 UI を HPB 風カレンダーに振り切るか、LINE チャット予約のみで行くか

**結論**：**二重 UI 戦略**
- 顧客向け：HPB 風カレンダー UI（LIFF 実装）
- オーナー向け：AI 秘書体験（チャット予約も裏で常設）

**理由**：
- HPB 解約の最大の障壁 = 「顧客が予約の仕方が分からなくなる」恐怖
- HPB 風 UI を Secleva に持つことで「**顧客体験は変えずに HPB 解約できる**」を訴求軸化
- 50代女性オーナーが「お客様に説明できる」という安心感
- HPB と Secleva は **顧客体験では競合せず、コスト構造でだけ競合する**形に持ち込める

### B. 漫画クリエイティブ → **採用（認知フェーズに限定）**

**論点**：実写広告と漫画シリーズ、どちらが ROI 良いか

**結論**：**Phase 1 = 漫画、Phase 2 = LP直訴求** の役割分担
- 漫画 5 本 A/B → 勝ち筋に予算集中
- AI 生成（Midjourney + ChatGPT 脚本）で 1 本 ¥3,000-5,000、初期投資 ¥30,000 程度

**シリーズ案**：
- 「整体院 山田さんの 1 日」（電話で施術中断 → AI が裏で対応）
- 「お客様の声で動く秘書」（"明日 14時で" → AI が予約完了）
- 「ホットペッパー解約物語」（5万円が浮いた、子供の習い事に回せた）

**注意**：漫画は認知フェーズ向き、コンバージョン直接訴求には弱い → LP に必ず誘導

### C. SNS 配分 → **採用（精緻化）**

**論点**：X 続けるか、Threads に振り替えるか

**結論**：**Instagram 本拠点 + Threads 補助 + Note 長文**、X は完全撤退
- 広告予算：Instagram / Facebook / Google
- オーガニック：Instagram カルーセル（漫画展開）+ Threads（本音・拡散）+ Note（長文）
- X 撤退理由：整体院オーナー層が不活性、罵倒文化、検索流入弱い

### D. オーナー向け「UI 見せずに楽さ訴求」 → **採用（精緻化）**

**論点**：機能訴求 vs 便益訴求、どちらを LP トップに出すか

**結論**：**LP トップ = 楽さ訴求 + 顧客側会話画面 1 枚**、オーナー操作 UI は隠す
- 50代女性 IT 低層に対して「UI スクショ = 難しそう」と感じさせる
- 表に出すのは **顧客 ↔ AI の LINE トーク 1 コマ** だけ（世界観の設定）
- オーナー管理画面・ダッシュボード・設定画面は **3 スクロール目以降**に格納

**便益訴求の数字・感情・比較**：
- 数字：「夜の電話対応 1日30分 → 0分」
- 感情：「ご飯を作る時間が戻ってきた」
- 比較：「電話に出れずチャンスを逃した、が消える」

### E. メッセージ階層と全体一貫性 → **3 階層構造で確定**

```
階層1（カテゴリ）：サロンオーナー専属の AI 秘書
階層2a（オーナー側）：あなたは、何もしなくていい
階層2b（顧客側）：お客様は、いつものホットペッパーのように予約できる
階層3（証拠）：6 ヶ月無料 / 月 ¥2,480 / 設定丸投げ / カード不要
```

**単一スローガン候補**：
- 「**変わるのは、あなたの時間だけ。**」（顧客は変わらない × オーナーは激変、のコントラスト）
- 「**お客様の予約は、いつものまま。**」
- 「**秘書がいれば、こうなる。**」

→ 最終選定は Yuto 判断。LP 実装時に A/B も視野。
