# Secleva 店舗ページ リッチ化 デザインリサーチ

## 目的
個人サロン（マッサージ・整体・スナック等）の店主が、自分の店として「使いたくなる」店舗ページに進化させる。  
リテラシー低層が操作しても破綻しない編集UIと、MEOで上位を狙える情報設計を両立させる。

---

## 1. 現状ページ分析（/SHOP-11C6）

| 項目 | 現状 | 改善方向 |
|---|---|---|
| 構造 | 縦1カラム、6セクション | 維持。順序を MEO 観点で再設計 |
| ビジュアル | 写真ゼロ | メインビジュアル＋ロゴ＋ギャラリー追加 |
| 個性 | 配色固定、テンプレ感 | 3テンプレ切替で「自分の店っぽさ」 |
| MEO | 構造化データ未実装、写真なし、評価なし、特徴タグなし | 構造化データ自動付与＋写真＋特徴タグ |
| 信頼形成 | キャッチコピー1行のみ | スタッフ紹介・FAQ・SNSリンク（任意） |

キャプチャ：`current-shop-page-mobile.png`

## 2. リサーチ：MEO・店舗LP 参考

### A. Google マップ（MEO のゴール状態）
キャプチャ：`ref-google-maps-search.png`

Google マップ検索結果で**ユーザーが一瞬で判断する情報**：
1. **店舗写真**（一覧サムネ＋詳細パネル左カラム）
2. **評価★・口コミ件数**（信頼の第一指標）
3. **業種カテゴリ**（リラクゼーション／エステ／整体院 等）
4. **営業時間ステータス**（営業中／営業時間外）
5. **「サイトを見る」CTA**（公式ページへの導線）
6. **「オンラインで予約」CTA**（その場で予約完結）

→ Secleva の店舗ページは**この6要素を兼ね備えること**が MEO 強化の最低条件。  
→ 特に **写真・評価・営業時間ステータス** は構造化データ（LocalBusiness schema）で自動付与すべき。

### B. ホットペッパービューティー（業界スタンダード）
キャプチャ：`ref-hotpepper-relax-top.png`

サロン業界で店主が「見慣れている」UI。Secleva の店舗ページがホッペとまったく違うUI言語だと違和感を与える。  
**取り入れる要素：**
- 上部：写真サムネ＋エリアタグ＋業種タグ
- 中段：「あなたに合わせて探した」レコメンド型の信頼演出
- 写真は**正方形グリッド**でガラリッと並べる
- 店舗詳細：写真→キャッチ→特徴タグ→メニュー→クチコミ→アクセス の順

→ Secleva では「クチコミ」までは Phase A で不要、写真とタグで近づける。

## 3. リサーチ：テンプレ切替型SaaS 編集UI

### C. ペライチ（リテラシー低層 No.1 シェア）
キャプチャ：`ref-peraichi-top.png`、`ref-peraichi-templates.png`

- TOPコピー：**「初期費用0円、ページ完成まで30分」**
- CTA：「1ページ無料でプロに依頼する」「自分で作成する」と**2段階の入口**
- テンプレート：業種別カテゴリで5〜10種ずつ、写真サムネで選ばせる

**学び：**
- 「自分でやる」と「依頼する」の二択を最初に出すと、リテラシー低層は迷わない
- テンプレ選択は**写真サムネ一覧**が最短。テキスト説明は副次

### D. lit.link（編集の単純化 No.1）
キャプチャ：`ref-litlink-top.png`

- 各リンクを**カード単位**で追加・削除・並び替え
- 写真・色・アイコンが**ブロック単位**で完結
- 「画像をアップして、テキスト入れて、保存」の3アクションで1ブロック完成

**学び：**
- Secleva 編集画面も**カード型ブロック**を踏襲すべき
- セクション単位で「表示する／しない」のON/OFFスイッチを採用
- ブロックは**ドラッグ&ドロップで並び替え**できると、低リテラシー層でも自分で構成変更できる

### E. STUDIO（テンプレートの世界観演出）
キャプチャ：`ref-studio-templates.png`

- テンプレ一覧は**雑誌ライク**な写真+1行コピー
- それぞれが**完成イメージ**として独立した世界観を持っている
- マッサージ／和モダン／ナイト系すべての方向性が STUDIO テンプレに既存サンプルあり

**学び：**
- Secleva の3テンプレ選択画面は「雑誌の表紙を選ぶ」UI に寄せる
- 「テンプレA」と書かず、**「クリーン白基調」「和モダン墨色」「ナイト黒×ゴールド」**等、雰囲気が一目で伝わる名前を付ける

## 4. 確定：5テンプレートの方向性

### T1：クリーン（白×LINE緑）
- **想定業種**：マッサージ／リラクゼーション／揉みほぐし（メインセグメント）
- **配色**：背景 #FFFFFF、アクセント #00B900（LINE グリーン）、テキスト #1F2937
- **フォント**：Noto Sans JP（既存ブランド踏襲）
- **特徴**：現状ベース、写真と余白で清潔感、Secleva デフォルト
- **使用比率予想**：35%

### T2：和モダン（生成り×墨黒×木目）
- **想定業種**：整体院／治療院／鍼灸／和系サロン
- **配色**：背景 #F5F1E8（生成り）、アクセント #1A1A1A（墨黒）、サブ #8B6F47（木目）
- **フォント**：Noto Serif JP（明朝で和の落ち着き）
- **特徴**：縦書き寄せキャッチ、木目テクスチャ、施術後の余韻
- **使用比率予想**：20%

### T3：ナチュラル（生成り×木目×グリーン）
- **想定業種**：アロマ／ハーブ／リフレ／オーガニック系
- **配色**：背景 #FAF7F2（オフホワイト）、アクセント #6B8E5A（モスグリーン）、サブ #C9A87C（テラコッタウッド）
- **フォント**：Noto Sans JP + Lora（英字混在で柔らかさ）
- **特徴**：植物・木目テクスチャ、写真にエッジ柔らかいオーバーレイ
- **使用比率予想**：15%

### T4：エレガント（ネイビー×ゴールド）
- **想定業種**：高単価エステ／隠れ家サロン／プライベートメニュー専門
- **配色**：背景 #FFFFFF、アクセント #1A2A4A（ディープネイビー）、サブ #C9A86A（シャンパンゴールド）
- **フォント**：Noto Serif JP + Cormorant（セリフ混在で品格）
- **特徴**：細罫線、上質な余白、高級ホテル風レイアウト
- **使用比率予想**：15%

### T5：ナイト（黒×ピンクゴールド×ネオン）
- **想定業種**：スナック／ガールズバー／ナイトサロン
- **配色**：背景 #0F0F12（漆黒）、アクセント #E8B4A0（ピンクゴールド）、サブ #FF6B9D（ネオンピンク）
- **フォント**：Noto Sans JP Bold（太字でインパクト）
- **特徴**：暗背景、ネオン風グラデ、写真は彩度高め、ボトル文化を意識
- **使用比率予想**：15%

→ 上記5種で、Sevleva 想定の主要セグメント95%以上をカバー。  
→ T1がデフォルト（新規開設時の初期テンプレ）、他4種は業種ヒアリングからレコメンド。

## 5. 最小編集スコープ（Phase A）

ユーザー（個人サロンオーナー）が編集画面で触れる項目：

| 項目 | 操作 |
|---|---|
| **テンプレート選択** | 3つから1タップ |
| **店舗ロゴ** | ドラッグ&ドロップ or タップでアップロード（推奨：512×512px、円形に自動トリミング） |
| **メインビジュアル** | 同上（推奨：1200×800px、上部フル幅表示） |
| **ギャラリー** | 最大6枚、まとめてアップロード可能、横スワイプ表示 |
| **店舗特徴タグ** | チェックボックス選択（女性専用／個室／駅近／駐車場あり／深夜営業／キッズOK／クレカ可 等、12〜15項目から複数選択） |

その他（店名・住所・予約ボタン・メニュー・営業時間・アクセス）は**既存のまま**。

## 7. /aidesigner で生成するモック

### 必要なモック数（計8枚）
- **公開ページ**：5テンプレ × 1画面 = **5案**（モバイルファースト）
- **編集画面**：**3画面**（テンプレ選択 → ブロック編集 → プレビュー）

### 共通プロンプト要素
- 想定ペルソナ：50代女性個人サロンオーナー、スマホ操作のみ、テキスト入力は苦手
- 端末：iPhone 15（375×812 をベース、ただし 390×844 で確認）
- ボタン高さ：48px 以上
- フォントサイズ：本文 16px 以上
- タップ可能領域：最低 44×44px

### モック生成順序
1. **T1 クリーン**（公開ページ・モバイル）  
2. **T2 和モダン**（公開ページ・モバイル）  
3. **T3 ナチュラル**（公開ページ・モバイル）  
4. **T4 エレガント**（公開ページ・モバイル）  
5. **T5 ナイト**（公開ページ・モバイル）  
6. **編集画面：テンプレ選択**（既存 admin にマージする想定）  
7. **編集画面：ブロック編集**（カード型UI、ON/OFF・並び替え）  
8. **編集画面：プレビュー**（リアルタイム同期）

### 編集画面マージ前提（重要）
3 枚の編集画面モックは「単体ページ」ではなく、**既存の Secleva 管理画面（`mockups/A_pure-line/admin.html`）にコンポーネントとしてマージ**される。  
そのため以下を満たす構造で生成する：

- **デザイン言語の統一**：既存 admin の配色／タイポ／余白／アイコン／ボタン形状を踏襲（A_pure-line ベース）
- **モジュラー構造**：各セクション（テンプレ選択カード、ブロック編集パネル、プレビューフレーム）が**独立した HTML パーシャル**として切り出せる
- **クラス命名**：BEM 風 or Tailwind ユーティリティで再利用可能に
- **エンジニアへの渡し方**：
  - HTML はファイル分離（admin/template-select.html / block-edit.html / preview.html）
  - 各ファイルの先頭にコメントで「どこに差し込むか」「依存コンポーネント」を明記
  - 画像・アイコンは `branding/` 配下の既存資産を参照
  - インタラクション仕様は HTML 内コメントで補足（モーダル開閉・ドロップゾーン・ON/OFFスイッチ等）
