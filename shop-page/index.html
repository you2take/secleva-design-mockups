マージ・実装メモ

  • 公開ページ5案：全テンプレで共通の10セクション順序を遵守。CTAは全て LINE緑 #06C755 でブランド一貫性を確保。
  • 編集画面3案：本番 secleva.com/owner 配下に統合される想定。同じスタック（Tailwind CDN / Noto Sans JP / Phosphor Icons / line色 #06C755）。/owner 既存ナビに「店舗ページ」項目を新設し、 /owner/shop-page/ 配下に3画面（template-select / edit / preview）を実装する想定。
  • BEM命名：.template-card / .shop-block / .preview-frame を採用。状態は --selected / --disabled / --draft。
  • 想定ペルソナ：50代女性個人サロンオーナー。本文16px以上、タップ領域44×44px以上、ボタン高さ48px以上を全画面で遵守。
  • 編集UI文言：「保存」→「とりあえず保存」、「公開」→「お店ページを公開する」、「決定」など、業務語を低リテラシー向けに翻訳。
